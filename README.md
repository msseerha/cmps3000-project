# Marketplace System

This is a group project for the course **Computational Thinking and Problem Solving (CMPS3000)** at **SAIT** (Fall 2026 term).

A Python-based command-line marketplace platform built using Object-Oriented Programming (OOP) principles.

## Features

- **Multi-Role Authentication**: Secure login and role-based menus for **Buyers**, **Sellers**, and **Admins**.
- **Buyer System**: Search catalogue, filter by price/seller, manage a shopping cart, save payment info, track yearly expenses, and earn automatic membership tier upgrades (Gold/Platinum discounts).
- **Seller System**: List new items, update prices, remove listings, view active inventory, check sold history, view delisted items, and submit admin appeal requests.
- **Admin System**: Delist items with reasons, view all registered users, grant or revoke admin rights, delete user accounts, reset passwords, unlock locked accounts, and broadcast custom alerts.
- **Notification System**: Dynamic alert logging for custom messages, sold/delisted tracking, and upgrade perks.
